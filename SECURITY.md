# Security policy

Report a security problem in BoxOps privately, not in a public issue, as
[docs/security.md](docs/security.md#reporting-a-security-problem) says:
through GitHub's private vulnerability reporting (the **Security** tab →
**Advisories** → **Report a vulnerability**), or, if you can't use it, by
email to allen@veryboringdata.co.

That page also says how BoxOps keeps the code a roadmap's site runs to the
code it released, how to check a release, and the risks that remain.
